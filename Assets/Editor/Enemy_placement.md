# 敵配置ルール

敵をゲーム内に配置する際の統一ルール。
EditorScript で敵を生成する時はこのルールに従う。

---

## 📐 敵配置の基本ルール

### 配置範囲（Room 座標）

敵は Room の座標範囲内に配置する：

```
X 範囲: Room.minXBoundary ～ Room.maxXBoundary
Y 範囲: Room.YBoundary ～ Room.maxYBoundary
```

**例：Room8 の場合**
```
X: 260 ～ 300
Y: -15 ～ 10
```

敵は上記の範囲内にランダムまたは意図的に配置する。

---

## 🎯 敵の配置パターン

### パターン A: 単体配置（ボス敵）

**用途:** Enemy3, Enemy4
**敵数:** 1 個
**位置計算:**
```
X = Room.minXBoundary + (Room の幅) / 2  （Room 中央）
Y = 任意（Room の Y 範囲内）
```

**例：Room8 に Enemy4 を配置**
```
X = 260 + (300-260)/2 = 280
Y = 20（天井から降下させる場合は高めに）
```

---

### パターン B: 複数配置（基本敵）

**用途:** Enemy2D
**敵数:** 2～3 個
**位置計算:**
```
X 間隔 = (Room の幅) / (敵数 + 1)
X₁ = minX + 間隔
X₂ = minX + 間隔 × 2
X₃ = minX + 間隔 × 3

Y = 固定（Room.YBoundary + 1）
```

**例：Room4（X: 180～220, 幅40）に Enemy2D を 3 個配置**
```
間隔 = 40 / 4 = 10
X₁ = 180 + 10 = 190
X₂ = 180 + 20 = 200
X₃ = 180 + 30 = 210
Y = 0 + 1 = 1
```

## 📊 Room ごとの敵配置設定

### Room1～2（初期 Room）
```
敵なし（チュートリアル）
または Enemy2D × 1（学習用）
```

### Room3～4（初期～中盤）
```
敵タイプ: Enemy2D または Enemy3
敵数: 1～2 個
配置: パターン B（複数配置）
```

### Room5～7（中盤）
```
敵タイプ: Enemy3
敵数: 1～2 個
配置: パターン A または B
```

### Room8～12（後期）
```
敵タイプ: Enemy3 または Enemy4
敵数: 1 個（ボス敵）
配置: パターン A（単体配置）
```

## 🔧 配置実装時のチェック項目

- [ ] Room の minXBoundary, maxXBoundary を確認（Areacover.md）
- [ ] Room の YBoundary, maxYBoundary を確認
- [ ] 敵タイプを選択（敵選択基準に従う）
- [ ] 敵数を決定（難易度に応じて）
- [ ] 敵の X, Y 座標を計算（上記パターンに従う）
- [ ] EditorScript で敵を生成
- [ ] Enemy_report.md の敵配置メモを更新

## 📝 配置計算例

### Room3 に Enemy3 を単体配置

```
Room3: minX = 80, maxX = 120, Y = 0

X = 80 + (120 - 80) / 2 = 100
Y = 1

配置: (100, 1, 0)
```

### Room11 に Enemy2D を 2 個配置

```
Room11: minX = 358, maxX = 398, Y = -15, maxY = 10

間隔 = (398 - 358) / 3 = 13.33
X₁ = 358 + 13.33 = 371.33 ≈ 371
X₂ = 358 + 26.67 = 384.67 ≈ 385
Y = -15 + 1 = -14

配置 1: (371, -14, 0)
配置 2: (385, -14, 0)
```
