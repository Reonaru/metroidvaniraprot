# Phase 3 実装計画：EnemyShield テスト実行と検証

## 目標
TestShield.unity シーンでプレイテストを実行し、盾役敵 EnemyShield の動作を検証する。
この段階では、既存実装の動作確認に注力し、他の敵パターン実装はこのフェーズ完了後に進める。

---

## 前提条件
以下が完了済みと仮定：
- ✓ EnemyShield.cs の実装（盾ロジック、耐久度管理）
- ✓ TestShield.unity テストシーンの作成
- ✓ プレイヤー・敵・弾の基本相互作用

---

## Phase 3 詳細手順

### ステップ 1: テスト環境の確認
**目的:** テストシーンが正常に動作する状態か確認

- [ ] TestShield.unity シーンが存在し、開くことができるか
- [ ] プレイヤーキャラクターが配置されているか
- [ ] EnemyShield が正しく配置されているか
- [ ] プレイヤーの弾発射機能が動作するか

**実行方法:** Unity エディタで TestShield.unity を開き、Play モードで起動

---

### ステップ 2: 防御範囲の検証
**目的:** 盾役敵が正しい範囲でプレイヤー弾を防ぐか確認

**検証項目:**
- [ ] 敵の前方から弾を発射 → 盾が防ぐ（盾が有効と判定される）
- [ ] 敵の背後から弾を発射 → 盾が効かない（通常ダメージ処理）
- [ ] 敵の左右から弾を発射 → 設計仕様に合わせて動作
- [ ] 複数の弾を同時発射 → すべてが盾判定で処理される

**記録内容:**
- 防御範囲が仕様通りか（例：前方180度 / 全方向）
- エッジケースで問題が発生しないか

---

### ステップ 3: 耐久度・破壊の検証
**目的:** 盾耐久度が正常に減少し、破壊されるか確認

**検証項目:**
- [ ] プレイヤー弾が盾に当たるたびに耐久度が減少
- [ ] 耐久度がゲーム画面に表示されているか（UI / デバッグ表示）
- [ ] 耐久度が設計値（例：3 回）に到達するまで盾が有効
- [ ] 耐久度が 0 になると盾が破壊される
- [ ] 破壊時のエフェクト・音声が再生される

**記録内容:**
- 耐久度の初期値 / 現在値
- 実際の破壊までの攻撃回数
- ビジュアル・オーディオフィードバックの有無

---

### ステップ 4: 破壊後の動作検証
**目的:** 盾破壊後、敵が期待通りに動作するか確認

**検証項目:**
- [ ] 盾が破壊されたら敵が直接ダメージを受ける（盾有効時は受けないはず）
- [ ] 盾破壊後、敵の移動速度が変わるか（仕様に準じて）
- [ ] 敵の防御状態が解除され、通常敵として機能
- [ ] スコア加算やドロップアイテムが正しく処理される（実装済みの場合）

**記録内容:**
- 破壊後の敵の状態変化
- その後の攻撃で敵がダメージを受けるか

---

### ステップ 5: 複数敵パターンテスト（オプション）
**目的:** 盾役敵が後衛敵を保護できるか確認（複数敵シーンがある場合）

**検証項目:**
- [ ] 盾役敵がプレイヤー弾を遮蔽し、後衛敵を守っている
- [ ] プレイヤーが盾役の横から迂回して後衛敵を直接攻撃できるか
- [ ] 盾役破壊後、後衛敵が通常通り攻撃される

**記録内容:**
- 複数敵の連携が仕様通りか

---

## テスト実施手順（実行フロー）

```
1. TestShield.unity を開く
2. Play ボタンで実行開始
3. プレイヤーで敵に近づく
4. 敵の前方から弾を複数発射
5. 盾が壊れるまで継続
6. 盾破壊後の敵動作を確認
7. 必要に応じてリプレイして他の角度からテスト
```

## 数値調整フェーズ（NG / 要調整が発生した場合）

テスト結果に基づき、以下を調整：

### A. 盾耐久度の調整
- 壊しやすすぎる場合 → 耐久度を増加
- 壊しにくすぎる場合 → 耐久度を減少
- **目標:** プレイヤーが2〜5秒程度で盾を破壊できるバランス

### B. 防御範囲の調整
- 防御範囲が広すぎる / 狭すぎる場合 → 判定を修正
- **確認方法:** デバッグで判定範囲を可視化

### C. ビジュアル・オーディオの調整
- 破壊エフェクトのタイミング・見た目
- 耐久度表示の位置・サイズ
- 破壊音の音量・種類

### D. ゲームバランス調整
- 敵の移動速度（盾有効時 / 無効時）
- 敵の攻撃頻度
- ドロップアイテムの量

## Phase 3 完了条件

以下をすべて満たしたら Phase 3 を完了とする：

- ✓ 防御範囲が意図通りに機能している（敵の前方で防ぐ、背後で防ぎない）
- ✓ 耐久度システムが正常に動作している（減少→破壊までの流れ）
- ✓ 破壊時の動作が設計仕様に合致している（ビジュアル・敵状態の変化）
- ✓ 盾破壊後、敵が直接ダメージを受ける
- ✓ ゲームバランスが適切（難易度が妥当、テストして違和感がない）
- ✓ テスト結果がドキュメント化されている

## 留意事項

- テスト中に見つかった不具合は、**迷わず EnemyShield.cs に記録・修正**
  （微調整だからと放置しない）

- 複数回のテストが必要な場合、毎回同じプレイパターンで再現性を確認
